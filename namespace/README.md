=============================================================================================
語言         核心認證單位     範例                                     特色
=============================================================================================
Node.js      實體檔案         const m = require('./math'); m.add();    沒有namespace概念，只認硬碟路徑。
---------------------------------------------------------------------------------------------
PHP          虛擬註冊         use App\User; $u = new User();           namespace 跟路徑兩條平行線，靠 Composer 綁定兩者。
---------------------------------------------------------------------------------------------
Python       層級疊加         import utils.math; utils.math.add()      目錄即空間，像剝洋蔥般層層點(.)進去。
---------------------------------------------------------------------------------------------
Go           目錄黏合         import "pkg/utils"; utils.Add()          極致扁平化，同目錄檔案融合成一個 package。
