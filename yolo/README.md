## 文件說名
1. yolo 是一種算法名稱作用於影像辨識

2. COCO 的定位

COCO dataset 不是：

❌ 已训练好的资料
❌ 第一批“训练后的知识”
❌ 模型基础权重

它是：

✔️ 人工整理 + 标注好的图像数据集（dataset）

3. yolo**.pt 文件：
 yolov8n.pt 是一個包含算法+官方已經訓練完成的模型。可以開箱即用

4. dataset 相當自己配置的  coco， 有標記圖片跟 txt

## 常見用法
1. 直接把  yolov8n.pt 拿來檢查圖片，可以辨識官方的特定的物件
2. 把  yolov8n.pt 用 coco 資料集合訓練，可以辨識 coco 資料中的物品
3. 把 yolov8n.pt 用 自己定義的 資料集合訓練，可以辨識自己定義的資料物品
